# Домашние NES-ром — происхождение и лицензии

Заглушка раздаёт две домашние (homebrew) NES-игры. Обе распространяются
их авторами открыто, обе — NROM, 40976 байт, работают на ядре FCEUmm (WASM).

## RoboRun (`roborun.nes`)
- Автор: heaven-hm. Репозиторий: https://github.com/heaven-hm/roborun-nes
- Файл взят из релизного каталога автора: `build/RoboRun-NES_1.1.nes` (v1.1, 40976 B)
- Лицензия: GNU GPL-3.0 (полный текст — `LICENSE-ROBORUN`)
- Исходный код игры доступен постоянно по тому же адресу, откуда взят бинарный дамп
  (раздел 6 GPL-3.0: исходники «свободно доступны по общедоступной сети» — тот же
  репозиторий). При запросе предоставляется копию исходников на носителе,
  действительная не менее 3 лет.
- Игра собиралась под PAL/Dendy, поэтому в реестре страницы для неё выставлен
  регион `Dendy` (опция ядра `fceumm_region`); на NTSC-тайминге она показывает
  предупреждение о неверном видеорегионе.

## Falling (`falling.nes`)
- Автор: tragicmuffin (xram64). Репозиторий: https://github.com/xram64/falling-nes
- Файл взят из корня репозитория автора: `falling.nes` (40976 B)
- Лицензия: MIT (полный текст — `LICENSE-FALLING`)

## Эмулятор: FCEUmm (`cores/fceumm/`)
- Точное libretro-ядро FCEUmm, собранное в WebAssembly: `fceumm.js` (Emscripten-склейка)
  + `fceumm.wasm` (собственно ядро). Лицензия — GNU GPL-2.0 (полный текст — `LICENSE-FCEUMM`).
- Исходники ядра: https://github.com/EmulatorJS/libretro-fceumm ; сборка в WASM взята из
  npm-пакета `romdev-core-fceumm@0.13.1` (https://github.com/monteslu/romdev).
- Хост-страница (`nes-engine.js`) — собственный код страницы, ограничений на распространение не имеет.
- Полные исходные тексты ядра в сборке предоставляются по письменному запросу
  (раздел 3b GPL-2.0, предложение действительно не менее 3 лет); сборочные скрипты —
  в указанных репозиториях.

## «Своя ROM»
Страница умеет открывать `.nes`-файл, выбранный пользователем: он читается
`FileReader` в браузере и никуда не отправляется — на сервере таких файлов не появляется.

Проверка дампа: первые 4 байта `4E 45 53 1A` («NES\x1A»), заголовок iNES.
