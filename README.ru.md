## Быстрая установка

Установите панель на Ubuntu одной командой:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/GurovNA/Veil/main/install.sh)
```

> Панель запускается как `vpnpanel.service` (управляется через `systemctl`),
> веб-интерфейс доступен по HTTPS: `https://<IP-сервера>:8443`.
> Первоначальные логин и пароль выводятся при установке (файл `FIRST-LOGIN.txt`).

## Возможности

### Протоколы (18 из коробки)
- **VLESS**: Reality, XHTTP+Reality, WS, WS+TLS, TCP+TLS, gRPC+TLS, XHTTP+TLS
- **VMess** и **Trojan**: WS / TCP / gRPC + TLS
- **Shadowsocks** AEAD, **Hysteria2**
- **WireGuard** на kernel-модуле (`veilwg`) и **AmneziaWG** (`awg0`) — с PSK и генерацией личных `.conf`
- REALITY с SNI-валидацией, настраиваемые TLS-отпечатки (Firefox/Chrome/Safari/iOS/Android)

### Подписки и клиенты
- Единый URL `/sub/<token>`: base64-список для v2rayNG/NekoBox/Hiddify, sing-box JSON, формат для **INCY** — по UA или `?format=`
- Публичная страница подписки `/p/<token>`: статус, трафик, QR-коды, каталог приложений с deep-link'ами, скачивание `WireGuard.conf` / `AmneziaWG.conf`
- Заголовки `subscription-userinfo` (трафик/остаток/срок) с корректными единицами для каждого клиента
- Лимиты трафика и срок действия с автоблокировкой; онлайн и расход трафика через Xray Stats API
- **Циклы сброса трафика** (день / неделя / месяц / lifetime) с дельта-накоплением счётчиков, переживающим перезапуск Xray, плюс **Telegram-алерты** на 80 % лимита, при истечении срока и при автоблокировке
- **Лимит устройств на клиента**: активные публичные IP считаются по access-логу Xray; лишних панель банит на 2 часа через nftables
- **Кнопка «Все протоколы»**: клиент, созданный под одним протоколом, одним кликом добавляется во все включённые — WireGuard/AmneziaWG сразу попадают в подписку; WG/AWG отдаются однострочными ссылками `wireguard://` и `amneziawg://`, которые импортируют Shadowrocket/Happ/NekoBox
- **Приём оплат на `/p`**: карта (ЮKassa), крипта (CryptoBot), своя касса по HMAC или вручную — пополнение продлевает лимит/срок клиента без участия админа, бот отчитывается о платежах
- **Split-tunnel RU/IR** в конфигах клиентов (российское — напрямую, либо иранское — через прокси): панель ночами зеркалит актуальные geoip/geosite-наборы правил sing-box и раздаёт их с `/rulesets/`
- Отдельный полный sing-box-конфиг подписчика на `/sb/<token>` (TUN + mixed-порт, DNS и правила split-tunnel)

### Интерфейс и дашборд
- **Новый интерфейс** с боковым меню (включён по умолчанию) и переключателем на классический в «Оформлении»; выбор хранится на сервере
- **Полная мультиязычность: RU / EN / FA (RTL) / ZH** — интерфейс, страницы подписок и Telegram-бот; почти под каждым разделом — пояснение «объяснить простым языком»
- **Дашборд с живыми виджетами**: статус Xray с аптаймом, KPI «клиенты онлайн» и «трафик сегодня» с дельтой ко вчера, список активных протоколов, кольца CPU/RAM/диск, 30-дневный график трафика, лента событий и быстрые действия
- Мобильная раскладка: нижняя лента вкладок, компактные карточки, адаптивные сетки; повторные загрузки почти мгновенные — страница отдаётся gzip'ом с ETag

### Безопасность
- **Вход по passkey (Face ID / Touch ID / Windows Hello)** — собственный WebAuthn без сторонних сервисов; пароль остаётся запасным входом
- **Операторы с тонкими правами**: выдай поддержке доступ только к нужным вкладкам, владелец сохраняет полный контроль
- 2FA (TOTP), смена логина/пароля, троттлинг входов
- **fail2ban-lite для входа в панель**: нарушители банятся в nftables-множества с timeout (`veil_bans`), свой сеанс и приватные адреса не банятся; список активных банов с «Разбанить» в UI, баны переживают перезапуск
- **Prometheus `/metrics`** (под Bearer-токеном): трафик/лимит/срок/устройства по клиентам, баны, диск/RAM, срок сертификата и другое — генерация токена в один клик в настройках
- Управление сессиями: список (IP, user-agent, последний визит), отзыв одной или всех кроме текущей
- Журналы: аудит API-действий и история входов прямо в UI
- Собственный ACME-клиент Let's Encrypt с автореневалом; dynv6 DDNS с проверкой домена через DoH

### Обход блокировок и Telegram
- **Zapret2** (DPI-bypass) одним переключателем, веб-прокси на Nginx, **decoy-сайт** для обфускации: самодостаточная 8-битная NES-аркада (точный libretro-движок FCEUmm в WebAssembly + две домашние игры, геймпад/тач/клавиатура, загрузка своего .nes локально в браузере, без CDN и исходящих запросов)
- **Telegram-бот**: создание подписок с лимитами, список клиентов, перезапуск, алерты
- **telemt**: MTProto-прокси с web-настройками и переключением версий

### Диагностика и администрирование
- Вкладка «Диагностика»: метрики CPU/RAM/load, статус служб и портов, протокол-осознанный self-test (TCP/UDP), замеры **Globalping** из точек по всему миру с алертами в Telegram
- **Вкладка «Логи»**: журналы служб (Xray, telemt, nginx, панель, journald) в браузере — без SSH; рост системных логов ограничен автоматически (logrotate + лимит journald)
- Центр обновлений: панель / Xray / telemt с откатом на предыдущую версию; экспорт и импорт состояния (бэкап)
- PWA, темы, обои и логотип настраиваются из UI
- **Федерация нод**: принимать клиентов других панелей Veil через скоуп-токены Node API (`/api/ext/*`, rate-limit, аудит, мгновенный отзыв) и размещать своих клиентов на удалённых серверах — на панели-ноде Veil или на автономном `agent.py` (vless+reality, учёт трафика, автоблокировка, зеркало с тем же uuid добавляется в подписку; отпечаток сертификата — TOFU)
- **⚡ Автоподключение нод по SSH**: вводишь IP/логин/пароль чистого VPS — панель сама ставит xray и `agent.py`, поднимает systemd-службу, открывает порты и регистрирует ноду (пароль — однократно для установки ключа, не сохраняется). **Покрытие ДЦ Telegram** во вкладке «Proxy»: RTT, писатели и % покрытия по API telemt с настраиваемым порогом
