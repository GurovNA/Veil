Сайт, домен и HTTPS

Домен и DDNS (dynv6)

Сервер сам обновляет A/AAAA домена при смене IP. Когда записи актуальны, домен автоматически подставляется в ссылки клиентов.

Токен аккаунта dynv6 (Bearer, из раздела Keys на dynv6.com) + имя новой зоны. Зона создается, host и token зоны сохраняются автоматически, IP обновится сразу.

Let’s Encrypt

Реальный сертификат для домена (нужен свободный порт 80). Он автоматически подключается к TLS-протоколам (ws/grpc/xhttp) вместо самоподписанного. Автопродление раз в сутки.
