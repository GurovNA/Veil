Сайт, домен и HTTPS

📖 Полная инструкция: как настроить домен (нажмите, чтобы свернуть/развернуть)

Зачем нужен домен?

Панель генерирует ссылки для клиентов (VLESS, VMess, Trojan и др.). Если указать домен — ссылки будут красивыми (vless://...@ваш-домен:443), работать через CDN и не сгорать при смене IP сервера.

Шаг 1. Купите (или получите бесплатно) домен

Зарегистрируйте домен у любого регистратора (.ru, .com, .xyz и др.). Цены — от ~150₽/год. Бесплатные варианты (eu.org, .tk/.ml/.ga/.cf) часто нестабильны — лучше использовать платный.

Шаг 2. Настройте DNS (A/AAAA записи)

В панели регистратора домена (или в Cloudflare, если используете их NS) создайте две записи:

ТипИмя (Host)Значение (Value)TTL
A@ (или пусто)IPv4 вашего сервера300 (или Auto)
AAAA@ (или пусто)IPv6 вашего сервера300 (или Auto)

IPv4: —   IPv6: —

Если используете Cloudflare (проксирование — «оранжевое облако»): включите «DNS only» (серое облако) для этой записи, иначе TLS-протоколы (Reality, gRPC, XHTTP) не заработают.

Шаг 3. Впишите домен в поле ниже

В поле «Домен для ссылок» введите ваш домен (например: vpn.example.com или example.com). Нажмите «Проверить A-запись» — панель сама резолвит домен и покажет, совпадает ли IP.

Шаг 4. Если у вас динамический IP — используйте dynv6 (DDNS)

Если IP сервера меняется (домашний сервер, 4G-модем), настройте dynv6.com:

  1. Зарегистрируйтесь на dynv6.com → создайте зону (например: myvpn.dynv6.net)
  2. В настройках зоны получите Token (раздел Keys → Zone Token)
  3. Ниже в блоке «Домен и DDNS (dynv6)» впишите Host (например myvpn.dynv6.net) и Token → «Сохранить»
  4. Панель сама будет обновлять IP каждые 5 минут

Шаг 5. Получите настоящий сертификат Let's Encrypt

Для работы TLS-протоколов (VLESS-Reality, VMess-gRPC, XHTTP) нужен валидный сертификат. Панель умеет выпускать его автоматически через Let's Encrypt (порт 80 должен быть свободен):

  1. Убедитесь, что порт 80 открыт в фаерволе и не занят nginx/apache
  2. В блоке «Let's Encrypt» впишите email (для уведомлений) → «Выпустить сертификат»
  3. Включите «Автопродление» — панель продлевает сертификат за 30 дней до истечения

🔧 Частые проблемы

  • «A-запись не совпадает» — проверьте, что в DNS указан именно IPv4 сервера, а не Cloudflare IP. Отключите проксирование (серое облако).
  • Сертификат не выдаётся — порт 80 занят или закрыт. Проверьте: ss -ltnp | grep :80 — должен быть пусто. Временно остановите nginx: systemctl stop nginx.
  • Ссылки не работают — проверьте, что домен в поле «Домен для ссылок» написан без https:// и без слеша в конце.
  • IPv6 не работает — у провайдера/хостера может не быть IPv6. Оставьте только A-запись, AAAA не обязательна.

🔗 Полезные ссылки

  • Cloudflare DNS — бесплатный DNS с защитой от DDoS (не забудьте выключить прокси для VPN-записей)
  • dynv6.com — бесплатный DDNS с поддержкой IPv6
  • Let's Encrypt — бесплатные TLS-сертификаты
  • DNS Checker — проверка распространения DNS по всему миру

Домен и DDNS (dynv6)

Сервер сам обновляет A/AAAA домена при смене IP. Когда записи актуальны, домен автоматически подставляется в ссылки клиентов.

Токен аккаунта dynv6 (Bearer, из раздела Keys на dynv6.com) + имя новой зоны. Зона создается, host и token сохраняются автоматически, IP обновится сразу.

Let’s Encrypt

Реальный сертификат для домена (нужен свободный порт 80). Он автоматически подключается к TLS-протоколам (ws/grpc/xhttp) вместо самоподписанного. Автопродление раз в сутки.

🤖 Как создать и подключить бота

  1. Напишите @BotFather в Telegram
  2. Отправьте команду /newbot и следуйте инструкциям
  3. Скопируйте полученный Token (формат: 123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ)

📘 Инструкция: как добавить ноду (нажмите, чтобы развернуть)

📋 Как подключить удалённую панель Veil как ноду

  1. На той (удалённой) панели открой «Ноды → Node API» и создай токен со scope чтение + запись — он показывается один раз.
  2. Здесь: «+ Добавить ноду», тип «Панель Veil», адрес и порт её панели (например 5.23.45.67 : 8443) и этот токен.
  3. «Проверить» — панель запросит статус ноды по защищённому API; при успехе нода станет «🟢 онлайн», а её сертификат будет закреплён по отпечатку. Статус обновляется автоматически каждые 45 секунд.
  4. Чтобы этот сервер был доступен чужим панелям — создай токен в «Node API» ниже и передай его той панели. Её клиенты разместятся в существующих входящих этого сервера и будут помечены как внешние (🌐).
  5. Разместить своего клиента на ноде: в карточке клиента кнопка «🖥» (или галочка при создании). На ноде создаётся его зеркало, а в личную подписку клиента добавляется ссылка на ноду — клиент сам выберет сервер. Снять — кликом по бейджу «🖥 host».
  6. Лимиты и срок при правке клиента прокидываются на ноды автоматически; при удалении клиента его зеркала снимаются с нод.

💡 Режим агента (agent.py): если на сервере нет панели Veil — скопируй туда agent.py, запусти python3 agent.py (нужны xray и openssl), возьми токен командой python3 agent.py --token и добавь ноду с типом «Агент». Агент сам поднимет vless+reality на своём порту, ведёт учёт трафика и автоблокировку; клиент на него размещается той же кнопкой «🖥». Токен можно отозвать в любой момент — доступ прекращается немедленно.

⚡ Быстрее: «Автоподключение по SSH» — введи IP, логин и пароль, и панель сама установит xray и агент, поднимет службу и зарегистрирует ноду. Пароль нужен один раз для установки SSH-ключа панели и нигде не сохраняется.

⚡ Автоподключение ноды по SSH — панель настроит сервер сама

Нужен SSH-доступ к чистому VPS (Ubuntu/Debian/Alma с python3). Панель: подключится, установит xray (если нет), положит агент в /opt/veil-agent, поднимет службу veil-agent, откроет порты в файрволе и сама зарегистрирует ноду. SSH-пароль используется однократно (только для установки ключа панели), нигде не сохраняется; дальше — вход по ключу.
