Начало работы

Пять команд от голой Ubuntu до работающей панели, первый вход и короткий разбор того, что делать дальше — и на сервере, и в дереве исходников.

Что нужно

  • Ubuntu 22.04 или 24.04 LTS, чистая установка.
  • Права root: установщик отказывается работать без них.
  • Свободные порты: панель возьмёт 8443, если он занят — передвинет на ближайший свободный и скажет об этом вслух.
  • Домен, указывающий на машину, если нужен честный TLS-сертификат. Без домена панель работает с заглушкой CN=Veil.

Установка

Одной строкой — из публичного релиза (архив veil.tar.gz проверяется по veil.tar.gz.sha256 до распаковки):

bash <(curl -fsSL https://raw.githubusercontent.com/GurovNA/Veil/main/install.sh)

Из скачанного дерева — то же самое, но с интерактивным меню:

bash install.sh              # меню: установить / переустановить / удалить / показать адрес
bash install.sh --step 5     # выполнить только один шаг
bash install.sh --dry-run    # показать команды, ничего не выполняя
bash install.sh --lang en    # сообщения по-английски (по умолчанию — по локали)
bash install.sh --help       # список флагов

Шаги идут подряд: 0 preflight → 1 packages → 2 xray → 3 telemt → 4 zapret2 → 5 panel → 6 finish.

ШагЧто делает
0проверка прав, места и того, что машина готова
1пакеты: python3 curl openssl tar jq nftables qrencode ca-certificates unzip wireguard-tools certbot
2Xray (установщик XTLS) и юнит xray.service
3telemt → /opt/telemt, /etc/telemt, /var/lib/telemt и юнит telemt.service
4veil-zapret2 — обход блокировок
5панель: архив, /opt/vpnpanel, юнит vpnpanel.service
6итоги: адрес панели и куда смотреть

Переменные, которые задают установку без вопросов:

VEIL_DOMAIN=vpn.example.com VEIL_EMAIL=me@example.com bash install.sh --step 5
  • VEIL_PANEL_LOGIN — логин оператора (иначе генерируется).
  • VEIL_DOMAIN — домен панели, он же panel_domain.
  • VEIL_EMAIL — почта для Let's Encrypt.

Установка пишется в /var/log/veil-install.log (если /var/log недоступен — в /tmp/veil-install.log).

Первый вход

systemctl status vpnpanel.service           # юнит: ExecStart=/usr/bin/python3 /opt/vpnpanel/panel.py
sudo cat /opt/vpnpanel/FIRST-LOGIN.txt      # логин и пароль первого входа
journalctl -u vpnpanel -e                   # строка «Veil 2.17.48 слушает …»

Дальше — https://<адрес машины>:8443 в браузере. Юнит настроен на Restart=always с RestartSec=2 и LimitNOFILE=65535, поэтому упавшая панель поднимется сама.

Пароль из FIRST-LOGIN.txt меняют сразу. Файл лежит на диске, а учётная запись — лицо сервера. Смена — во вкладке настроек, там же включается второй фактор и passkey.

Что сделать в панели

  1. Входы. Выбрать протоколы, которые будут выдаваться (Reality, ws, gRPC, Hysteria2, WireGuard, AmneziaWG, MTProxy и остальные — семнадцать). Номера портов брать из таблицы на странице Обзор.
  2. Подписчик. Создать подписчика — панель заведёт клиентов выбранных протоколов и выдаст ссылку подписки /sub/<токен>, карточку /p/<токен> и конфиг sing-box /sb/<токен>.
  3. Домен и сертификат. Сказанный домен включает выпуск Let's Encrypt; без него ссылки уходят на адрес машины.
  4. Двойной прыжок. Вкладка прыжка: добавить фронт (тонкий nft-релей), произнести слово hop_public_host — и панель переложит адреса ссылок, DNS-записи зоны и книгу релея. Релей ставится скриптом /relay.sh с одноразовым токеном, который печатает _hop_add.
  5. Журнал. Все эти шаги попадают в аудит: событие названо и объяснено числом, поэтому «ничего не произошло» тоже видно.

Локальная правка

Прежде чем считать правку готовой, её проверяют тремя короткими мерками — они же стоят в CONTRIBUTING.md:

python3 -c "import ast; ast.parse(open('panel.py').read())"   # синтаксис панели
node --check index.html                                        # скрипт морды
bash -n install.sh                                             # синтаксис установщика

Затем — приборы. Деликатная выборка по любой правке из грани _pub_host, прыжка, мюкса и сертификатов занимает около шестнадцати минут:

cd backups/audit-2.16.1/gp
POOL=small bash battery.sh 727a

Полный прогон, живые ноги и прочие переключатели батареи — на странице Использование CLI. Там же описана красная база: прибор, который зелёный на байтах до правки, мерить нечего.
